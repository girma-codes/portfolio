04. Case Studies

Deep-dives into real problems I've solved — in Amharic & English.

ችግሩ / The Problem

Ethiopian artisans lacked a trustworthy online presence. Existing platforms charged high fees, didn't support Amharic, and had no local payment option — leaving 80% of handcraft sellers offline.

መፍትሔው / The Solution

Built a mobile-first e-commerce platform in both Amharic and English, integrated Telebirr and CBE payment gateways, and created an intuitive seller dashboard operable with low digital literacy.

ቴክኖሎጂው / The Tech

React, Node.js, MongoDB Atlas, Cloudinary CDN, Telebirr API, i18n localization, and a custom offline-capable PWA shell for low-connectivity areas.

Read Full Case Study Demo Video
ችግሩ / The Problem

Rural Ethiopian clinics operated with paper-based records. Internet outages disrupted patient care, records were lost, and staff needed a system requiring zero technical training.

መፍትሔው / The Solution

Designed an offline-first patient management system using IndexedDB and Service Workers. Data syncs automatically when connectivity is restored, with a touch-friendly interface in Amharic.

ቴክኖሎጂው / The Tech

Vue.js, Workbox PWA, IndexedDB, Express.js, PostgreSQL, and CouchDB sync protocol with conflict resolution.

Read Full Case Study Demo Video
ችግሩ / The Problem

Existing translation tools poorly handled Amharic morphology, resulting in inaccurate translations for official documents. Government and NGO staff wasted hours manually correcting outputs.

መፍትሔው / The Solution

Fine-tuned a multilingual transformer model on a curated Amharic-English corpus. Built a clean web interface with document upload, translation memory, and glossary management.

ቴክኖሎጂው / The Tech

Python, HuggingFace Transformers, FastAPI, React, Docker, and a custom Amharic tokenizer based on Ge'ez script segmentation rules.
